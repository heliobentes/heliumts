# Local experiment history

These reports preserve exploratory development measurements, including negative and mixed results. They are not product benchmarks or promises of lower AI cost. Tasks, protocols, package builds, cache state and sample sizes differ between studies; do not pool their results or infer large-project performance.

Absolute `/tmp/...` links refer to the original development host's scratch artifacts. They are **local provenance paths, not hosted downloads**, are not included in this repository or normal npm packages, and may no longer exist. The written reports retain those paths and hashes honestly; a public checkout cannot recover missing raw artifacts from the links alone. No model weights, dependency caches or raw trial workspaces are committed here.
